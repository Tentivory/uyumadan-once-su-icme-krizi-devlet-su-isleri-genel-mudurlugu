# uyumadan-once-su-icme-krizi-devlet-su-isleri-genel-mudurlugu
Yatağa girdikten sonra su içme ihtiyacını resmi kuraklık, milli bardak egemenliği ihlali ve musluk protokolü sapması sayan; yastığı baraj, 'biraz idare ederim' cümlesini su kesintisi ilan eden Genel Müdürlük. Gerçekten çalışır. Bardaklar artık barajdır.
